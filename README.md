# Simple Utils

A tiny utility library containing basic string and temperature conversion functions.

## Functions

- `reverse_string(text)` - Reverses the characters in a string
- `count_words(sentence)` - Counts words in a sentence
- `celsius_to_fahrenheit(celsius)` - Converts Celsius to Fahrenheit

## Usage

```python
from simple_utils import reverse_string, count_words, celsius_to_fahrenheit

# Example usage
print(reverse_string("hello"))  # "olleh"
print(count_words("hello world"))  # 2
print(celsius_to_fahrenheit(100))  # 212.0
```
